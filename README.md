# Flags_Transfer_Browser
ПЕРЕНОС CHROME FLAGS - FLAGS BROWSER ALL
====================

В архиве находятся 120 выбранных значений Chrome Flags.
Пароли, история, закладки, cookies и другие данные профиля сюда не включены.

БЫСТРЫЙ ИМПОРТ
---------------
1. Распакуйте ZIP в обычную папку.
2. Полностью закройте браузер, в который переносите флаги.
3. Запустите RUN_IMPORT.cmd.
4. Выберите браузер цифрой и подтвердите замену списка флагов.
5. Запустите браузер снова.

Перед изменением импортёр автоматически создаёт рядом с файлом Local State
резервную копию с именем вида:
Local State.flags-backup-20260809-123456

СОВМЕСТИМОСТЬ
-------------
Лучший результат будет при переносе в Google Chrome похожей версии. Подходят многие браузеры
Edge, Brave, Яндекс Браузер, Vivaldi и Opera основаны на Chromium, но наборы
флагов различаются. Неизвестные или удалённые флаги могут быть проигнорированы.

ВОССТАНОВЛЕНИЕ
--------------
Если браузер стал работать нестабильно:
1. Полностью закройте браузер.
2. Найдите созданную резервную копию Local State.flags-backup-...
3. Переименуйте текущий Local State, а резервную копию — в Local State.

ФАЙЛЫ
-----
chrome-flags.json  — точный экспорт списка enabled_labs_experiments.
import_flags.ps1   — импортёр с резервным копированием.
RUN_IMPORT.cmd     — удобный запуск импортёра.

ВАЖНО
-----
Chrome Flags — экспериментальные параметры. Некоторые значения могут снижать
безопасность, приватность или стабильность. Архив переносит исходный список без
изменений и не оценивает безопасность каждого флага.

КРАТКОЕ ОПИСАНИЕ
----------
Отключение эксперементальных функций браузеров, уклон на анонимность и уклон на минимальную отправку данных клиентам и сайтам
